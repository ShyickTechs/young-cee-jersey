# Young Cee Jersey / Sport Wears Enterprise — Demo

A Next.js demo online shop using the 5 jersey photos supplied for the Young Cee lead.

## Run it

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. In the terminal run:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000

## Important
- This is a sales demo, not a production ecommerce system yet.
- Prices are demo values and should be replaced with the seller's real prices.
- The WhatsApp number is the number provided in the chat.
- Replace/add product images and sizes when the client supplies the complete catalogue.
